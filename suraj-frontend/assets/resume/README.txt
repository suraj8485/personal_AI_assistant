Put your resume files in this folder with these exact names:

  resume.pdf
  resume.docx

The "Download PDF" / "Download DOCX" buttons on the home page
(in index.html, Resume section) already point here:

  href="assets/resume/resume.pdf"
  href="assets/resume/resume.docx"

If you'd rather use different filenames, just update those two
href values in index.html to match.
